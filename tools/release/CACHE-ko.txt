EMPRESS MEGAMIX - PC에서 런처 캐시 생성

기존 R171 설치 환경에 추가하는 선택 기능입니다. R171 빌더와 그에 맞는 캐시
엔진을 함께 사용하세요. 저장 장치에 쓰기 전에 PS2를 끄세요.

처음 한 번만 추가 실행 환경을 설치합니다.
    python -m pip install "wasmtime>=50.0.1,<51"
Linux/macOS에서는 필요하면 python 대신 python3를 사용하세요.
일반 ISO 생성, 추가 설치, 검증 명령에는 이 패키지가 필요 없습니다.
컴파일러, PS2SDK, 폰트도 필요 없습니다.

PC의 MEGAMIX 폴더와 PS2에서 실제로 사용하는 게임 데이터 경로를 지정합니다.
    python megamix.py cache "X:\MEGAMIX" --game-path mmce0:/MEGAMIX/
    python megamix.py cache "/media/USB/Games/BM" --game-path mass:/Games/BM/

mmce0:은 슬롯1, mmce1:은 슬롯2입니다. mass:와 mass0:도 서로 다른 캐시 키를
사용합니다. ELF의 위치가 아니라 런처가 사용하는 게임 데이터 경로를 정확히
입력하세요. 경로가 다르면 런처가 캐시를 사용하지 않고 다시 생성합니다.

PS2에서 사용할 launcher.cfg를 기준으로 생성하세요. 설정이 다른 위치에 있다면:
    python megamix.py cache "X:\MEGAMIX" --game-path mmce1:/MEGAMIX/ --config-dir "Y:\APPS\MEGAMIX" --settings-path mc0:/APPS/MEGAMIX/
--config-dir은 PC의 설정 폴더, --settings-path는 PS2의 설정 폴더입니다.
HOST 버전은 --game-path host:를 사용합니다.

debug.cfg의 debug와 prepprobe는0으로 두세요(debug 0 / prepprobe 0).
미완료 상태인 설정 저장, 추가 설치, 업데이트가 있다면 먼저 완료하세요.

게임 파일과 현재 설정의 복사본으로 생성한 뒤 런처의 복원 코드로 검증하고
캐시 파일만 씁니다. 설정, USB 바인딩, 스코어, 설치 정보, source.id는 바꾸지
않으며 다른 조건의 기존 캐시도 유지합니다. 폴더 선택, 구조에 영향을 주는 옵션,
설치된 디스크가 바뀌면 캐시를 다시 만들어야 할 수 있습니다.

전체 CS곡 환경에서는 약20MiB와 PC의 임시 공간이 필요합니다. 임시 드라이브가
가득 찼다면 --temp-dir "D:\Temp" 등으로 다른 위치를 지정할 수 있습니다.
복사 도중 중단됐다면 같은 명령을 다시 실행하세요. 불완전한 캐시는 런처가
거부하고 일반 재생성으로 돌아갑니다. 복사가 끝나기 전에는 장치를 뽑지 마세요.

별도 cache-tools ZIP에서는 "megamix.py cache" 대신 build-cache.py를 같은
인수로 실행할 수 있습니다. 이 작업에는 ISO나 release.mmr이 필요 없습니다.
Linux의 네이티브 비교는 통과했습니다. Windows/macOS 및 실기 검증은 아직입니다.
자세한 설명과 라이선스는 CACHE.txt 및 cache-engine/licenses를 참조하세요.
